# 云端验证版架构

浏览器 → Sites 身份网关 → Vinext API → D1 题目与作答事件 / R2 原图。

上传 → 浏览器重编码 → 私有原图保存 → 可选视觉模型 → 结构化草稿 → 学生校对 → 确认入库 → FSRS 到期任务 → 自评反馈 → 事务保存事件与排期。

## 与 v0.1 的差异

| 维度 | 原境内方案 | 当前 Sites 验证版 |
|---|---|---|
| 认证 | 管理员发放 Supabase 学生账号 | Sites 平台身份，私有访问 |
| 数据 | PostgreSQL + RLS | D1 + 服务端所有权检查 |
| 图片 | Supabase 私有桶 | R2 + 私有读取接口 |
| 识别任务 | 持久轮询 Worker | 上传内识别，失败手动整理 |
| 图片处理 | sharp 服务端重编码 | 浏览器 Canvas 重编码 |
| 部署目标 | 中国大陆 | Sites 验证环境，非境内正式服务 |

正式学生账号、境内存储、异步任务、真实模型测试和移动设备验收仍是试点上线前的依赖。Supabase 原工程完整保留于 deployments/mainland-nextjs，不与当前 D1 运行时混用。
