# 以 GitHub 和既有 Builds 收敛试点发布

2026-10-18 确认：当前 Cloudflare 试点以 GitHub 作为统一提交入口，复用现有 Workers Builds 作为唯一生产自动发布控制者；用户批准合并后自动发布。核清 Sites 与独立部署是否共享资源后冻结 Sites 托管版本的后续发布，同时保留资源和必要构建集成，以减少双目标漂移并避免为退出平台重写业务或破坏现有运行依赖。

正式学生上线另行验收。Sites 资源映射未验证，目前只阻塞其冻结，不阻塞独立试点的其他改造；此决策已确认，冻结和完整实施尚未执行。可调整的门禁、备份及应急操作规则以[持续开发与维护](../DEVELOPMENT.md)为准。
