## 最小生产窗口（M4-B，另行确认后执行）

1. **锁定候选。** 经用户批准先将堆叠 PR #2 收敛到 #1 所在分支，加入经审查的必要准备改动与文档；对最终 head 重跑全部三项检查及范围内集成验收。此前 head 的通过状态不自动继承。用户批准最终候选 SHA、生产操作清单及窗口；此时仍不合并 main。
2. **先建立恢复保障。** 经明确批准创建独立生产 archive、生产 ops/watchdog 并启用调度；不改应用 Worker。首个配套生产恢复点必须通过 manifest、数据库与引用图片读回校验，记录 schema/迁移版本和源版本；验证邮件绑定及通知送达。源数据只进入受保护的生产备份，不复制到测试资源。该步骤的失败停止应用切换；生产备份启用本身也属于待批准生产变更。
3. **收敛发布窗口。** 暂停现有 Builds 的生产自动触发，读回确认并检查/处理已有排队或运行构建，确保没有旧任务稍后覆盖版本。暂停触发不停止现有 Worker 服务。保留 PR 检查，安排独占窗口；任何额外提交使批准失效。
4. **准备短命令并恢复触发。** 自动触发暂停且队列清空后，为生产 Builds 注入模板要求的七个非密钥构建变量（生产与 Preview 资源分离），构建命令使用 `pnpm test:config && pnpm test && pnpm typecheck && pnpm build:release`；发布命令使用锁定依赖的 `pnpm exec wrangler deploy --config dist/server/wrangler.release.json`。读回设置，确认当前版本不变，再恢复自动触发并确认未意外构建。此时 main 仍未合并；独占窗口阻止其他提交，若恢复触发产生旧提交任务则停止并清理窗口，不能继续合并。
5. **用户批准合并触发单次发布。** 对最后确认的候选 SHA 执行合并，记录实际 main merge SHA；由原 Workers Builds 自动构建发布。核对实际源码、完整测试、生成配置及新 Worker 版本；不使用旧提交“重试”冒充新 SHA，也不以本机 CLI 直接发布应用。该顺序替代原未证实的“暂停时手动构建新 merge SHA”，依据见 M4-A 的权限与演练记录，仍需用户确认后实施。
6. **验收并关闭窗口。** 完成下表检查，确认 main 与生产版本的证据关联、无旧构建排队。后续维持用户批准合并 → 同一 Builds 自动发布。旧内联补写逻辑由仓库短命令替代，受限快照保留作窗口恢复依据。出现故障先控制队列，按下方边界处理。

生产窗口前重新读取良好版本，不能永久硬编码本次审计版本。若暂停触发机制无法在独立环境验证，保持原发布设置，改写方案后再确认，不在生产临时探索。

## Risk & Rollback

- **发布前失败：** 保持原应用版本与生产源数据不动，恢复已批准窗口内改过的 Builds 设置。若生产备份已启用，不因应用未切换而删除有效备份；其保留或暂停按事故原因记录并处理。
- **发布后明确由新版引起的应用故障：** 仅当发布前良好、连续两次关键检查失败、确认为该新版、旧版兼容当前数据/运行配置、且没有更新发布时，在线用户或 Agent 可按已授权范围回滚到窗口记录的良好版本。先阻止排队重试/自动构建重新覆盖，保留证据；回滚后复查版本、绑定与只读业务，不把回滚按钮成功等同于恢复。
- **配置问题：** 单独比对并恢复本窗口改变的 Builds 配置；Worker 版本回滚不能替代构建设置恢复。Access、密钥、资源删除、迁移不在有限代码回滚授权内，升级给用户处理。
- **数据故障：** 先停止扩大损害并保留原资源，向用户提交恢复点、预期损失、目标与切换差异，获独立批准后才恢复到同 schema 的全新空生产恢复资源。禁止直接清空原库，禁止套用当前测试恢复工具对生产执行。D1 Time Travel 仅为补助手段，需核实可用窗口，不能单独恢复配套 R2。
- **其余故障：** 邮件告警并等待用户，不因模型/网络故障盲目回滚。RPO ≤24 小时、RTO ≤4 小时是需证据支持的目标；计时包含发现、响应、审批、恢复和业务验收，依赖操作者在线及 Cloudflare 账户/平台可用，无无人值守回滚承诺。

Cloudflare [Builds 配置说明](https://developers.cloudflare.com/workers/ci-cd/builds/configuration/)确认构建设置用于下一次构建，重试使用重试时的配置，构建变量与运行时变量分离；因此窗口必须检查在途任务与实际 SHA。[回滚说明](https://developers.cloudflare.com/workers/versions-and-deployments/rollbacks/)明确版本回滚不恢复关联数据，资源/数据兼容性仍需核验。[运行限制](https://developers.cloudflare.com/workers/platform/limits/)与账户实际套餐共同决定容量，不能把脚本保护常量当作平台保证。
