# 产品规格 v0.1 | 中国大陆 / 小学与初中 / 仅学生账户

## 决策记录

- 目标用户：小学一至六年级、初中七至九年级学生。
- 初始学科：数学。每题允许学生记下错误答案及原因。
- 部署：生产服务器、数据库、原图与第三方视觉模型的实际数据处理位置优先选择中国大陆；上线前完成 ICP / 公安备案与合规审核。
- 账户：学生账号仅由管理员在核验监护人同意后发放。没有学生自主注册、没有家长或教师登录入口。
- 核心指标：题目识别纠错率、独立完成率、延迟重做正确情况、复习完成率。

## 首个闭环

1. 线下核验监护人授权，后台发放学生账号与初始密码。
2. 学生用手机网页登录。
3. 拍摄一张以单道题为中心的照片；客户端展示预览。
4. 后端纠正方向、压缩并去除 EXIF/GPS 等元数据后，将图片保存到私人存储桶，建立排队任务。后台 Worker 送视觉模型解析。
5. 模型输出严格 JSON，状态保持 `draft`，学生必须并排检查原图和文本、解析、年级与知识点。
6. 学生点击确认，生成 `review_states`，首次到期时间为当前时间。
7. 学生独立作答后看参考解析。提交正确与否、是否使用提示及四档自评。
8. 算法在服务端更新 FSRS 卡片，下次到期时间写入数据库；写入不可覆盖的 attempts 事件。
9. 进度页展示最近 100 次自评及到期任务，明确区分自评证据与客观判分。

## 角色和权限

| 身份 | 权限 |
|---|---|
| 未登录访客 | 仅登录页，不提供账户注册 |
| 学生 A | 仅本人图片、题目、反馈和到期记录 |
| 学生 B | 仅本人数据，不可访问 A 的数据 |
| 项目管理员 | 线下核验监护人授权，使用服务器脚本创建或删除学生账号 |
| AI Worker | 使用仅服务端存在的 Secret 执行待处理任务，不直接作为学生访问 |

## 数据语义和失效处理

- 区分 `source_image`、`question_markdown`、`recognition_notes`；识别成功 != 答案正确。
- 内容含几何图时，设置 `image_required` 并渲染受授权的原图。
- 没有学生错误过程的照片不允许 AI 假装诊断出实际错因；该字段为 `unknown`。
- 判断「独立正确」当前是学生本人声明（`evidence_type=self_report`），尚无自动数学判分。
- 一次评分可以被网络重复提交，使用 `submission_id` 去重，使用 `version` 进行并发检查。
- 回忆失败或查看提示都进入 `Again`；其他等级需在独立做对时才可应用。
- AI 任务最多尝试 3 次；超时任务可重新认领，失败不会自动入库。
- 上传大小限 6MB、格式只允许 JPEG/PNG/WebP，初版每日 20 张额度。
- 题目删除时删除原图及级联的复习历史。账户清除后应处理数据库备份的删除与留存策略。

## 当前暂缓

- 家长、教师、学校后台；批量试卷识别；自动批改主观题；BKT 掌握率；根据算法自动生成无限变式题；付费与榜单；手机号自主注册。

## 早期目标（待真实数据验证）

| 指标 | 验收目标/要求 |
|---|---|
| 关键题干识别准确率 | 在经过独立标注的 100 张多样化数学题图片上 >= 95%（按关键字段口径） |
| 异常识别处理 | 模型输出非法 JSON 不会污染题库；有失败提示和重试 |
| 入库完整性 | 原图可访问且只能由所属学生访问 |
| 幂等性 | 同一 submission_id 只产生一条学习记录 |
| 延迟正确率 | 观察第 7 / 14 天相似题表现，不提前声称提升 |
| 浏览器 QA | Android Chrome + iOS Safari 真机验证登录、拍照、横向公式滚动、失效会话、弱网重试 |

## 版本边界

v0.1 是试点实现，不能直接面向真实未成年人公开上线。需要完成监护人核验流程、合规文本/流程、生产账号风控、WAF 限流、备份、监控及备案。
